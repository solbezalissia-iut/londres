# Carnet de Londres — 21 → 30 mai 2027

Site de voyage jour par jour : horaires, comment aller à chaque endroit, réservations, budget et billets.
Fonctionne sur ordinateur et téléphone, même sans connexion une fois ouvert une première fois.

## Mettre le site en ligne avec GitHub Pages (gratuit, ~5 min)

1. Crée un compte sur **github.com** (si ce n'est pas déjà fait).
2. En haut à droite, clique sur **+** → **New repository**.
   - Repository name : `londres-2027` (ou ce que tu veux)
   - Coche **Public** (obligatoire pour GitHub Pages gratuit)
   - Clique sur **Create repository**.
3. Sur la page du dépôt vide, clique sur **uploading an existing file**.
4. Glisse **tous les fichiers de ce dossier** (index.html, app.js, data.js, sw.js, manifest.webmanifest, icon.svg, icon-192.png, icon-512.png, README.md).
   Le fichier `.nojekyll` est caché sur Mac/Windows : ce n'est pas grave s'il manque.
5. Clique sur **Commit changes**.
6. Va dans **Settings** → **Pages** (menu de gauche).
   - Source : **Deploy from a branch**
   - Branch : **main** et dossier **/ (root)** → **Save**.
7. Attends 1 à 2 minutes, puis recharge la page : l'adresse s'affiche en haut,
   du type `https://ton-pseudo.github.io/londres-2027/`.

### Sur ton téléphone

Ouvre l'adresse dans Safari (iPhone) ou Chrome (Android), puis
**Partager → Sur l'écran d'accueil**. Le carnet s'ouvre alors comme une appli, même dans le métro sans réseau.

## Tes billets

- Sur chaque étape payante ou réservée, bouton **« Ajouter un billet »**, ou onglet **Mes billets**.
- Tu peux ajouter des PDF, des photos ou des captures d'écran, avec le numéro de réservation.
- **Ils ne sont pas mis sur GitHub** : ils restent dans le navigateur de l'appareil où tu les ajoutes.
  C'est voulu, parce qu'un site GitHub Pages est public et que tes QR codes ne doivent pas l'être.
- Pour passer de l'ordinateur au téléphone : **Mes billets → Sauvegarder (fichier)**,
  envoie-toi ce fichier, puis **Restaurer une sauvegarde** sur le téléphone.

⚠️ Ne mets jamais tes billets (PDF, QR codes) dans le dépôt GitHub.

## Modifier le programme

Tout le contenu est dans **`data.js`** : jours, horaires, adresses, trajets, prix.
Sur GitHub, ouvre `data.js` → icône crayon ✏️ → modifie → **Commit changes**. Le site se met à jour en 1 à 2 minutes.

Après une modification, si le téléphone affiche encore l'ancienne version, ferme l'appli et rouvre-la avec du réseau.
