Modifier un voyage

Les détails de chaque voyage (horaires, trajets, réservations) sont chiffrés avec le code. Cette page sert à les modifier sans jamais mettre le texte en clair sur GitHub. Tout se passe dans ton navigateur.

1. Récupérer le fichier modifiable

Tu obtiens un fichier .prive.js. Ouvre-le avec un éditeur de texte (Bloc-notes, TextEdit en mode texte brut, VS Code…), modifie le programme, puis passe à l'étape 2. Ne l'envoie pas tel quel sur GitHub.

2. Chiffrer et préparer l'envoi

Tu obtiens un fichier .zip. Décompresse-le, puis sur GitHub :

  1. Ouvre ton dépôt, puis « Add file » → « Upload files ».
  2. Glisse les dossiers voyages et prive qui sont dans le zip.
  3. Clique sur « Commit changes ». Le site est à jour en une à deux minutes.
  4. Pour un nouveau voyage, ajoute aussi son nom dans voyages.js.
